## 最优性与正确性证据

* KKT + 强对偶最优性证书：对偶间隙 0、平稳性违反 0、互补松弛 4.9×10⁻¹⁴（全局最优）
* 独立求解器 CBC 交叉验证：13 个算例目标值一致到 10⁻⁹
* 独立算法动态规划复算：网格加密时间隙 0.21% → 0.07%，收敛到 LP 最优值
* 全年 48 096 个时段逐项复核：功率平衡/SOC 上下限/期末约束违反量 ≤ 10⁻¹¹
* 与可行规则型策略对比：优化策略节省 29.8% 购电费
