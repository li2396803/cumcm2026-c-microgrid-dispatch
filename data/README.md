## 可删除性

删除本目录不影响代码运行：`work/src/extract.py` 会优先读取环境变量 `CUMCM_DATA_DIR` 指向的附件目录，
其次读取 `<repo>/data/附件`；若两者都不存在，可直接使用仓库中已缓存的 `work/out/data.npz` 继续后续计算。

```bash
# 从原始附件重建数据缓存（默认路径即 data/附件）
cd work && python3 src/extract.py

# 或指定附件所在目录
CUMCM_DATA_DIR=/path/to/附件 python3 src/extract.py
```
